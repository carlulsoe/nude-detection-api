Your images stay transient.

Images are decoded and analyzed in memory. The service retains payment replay records and paid JSON results for retry recovery, without storing uploaded image files.

JPEG, PNG, and static WebP. See the pricing endpoint for upload limits.

A familiar HTTP interface.

Send raw image bytes to get an HTTP 402 payment challenge. An MPP client handles payment and retries the same request.

curl http://localhost:8000/v1/moderate \
  -H 'Content-Type: image/jpeg' \
  --data-binary @image.jpg
